## Example 1

Using the default ("dagre") layout engine:

````text
```d2svg {file="diagrams/example-1.d2"}
```
````

```d2svg {file="diagrams/example-1.d2"}
```

Using the "elk" layout engine:

````text
```d2svg {file="diagrams/example-1.d2", layoutEngine=elk}
```
````

```d2svg {file="diagrams/example-1.d2", layoutEngine=elk}
```
