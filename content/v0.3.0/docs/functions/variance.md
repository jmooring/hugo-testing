---
title: variance
---

The `variance` function returns the [sample variance][] of the given sequence of numbers.

Prior to v0.3.0, this function returned the [population variance].

[population variance]: https://en.wikipedia.org/wiki/Variance#Population_variance_and_sample_variance
[sample variance]: https://en.wikipedia.org/wiki/Variance#Population_variance_and_sample_variance
