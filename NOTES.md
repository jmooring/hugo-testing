## Notes

Footnote Approach: Advantages

- Automatic numbering, significantly streamlining reference management.
- Comprehensive reference inclusion at the page's bottom, with only cited sources visible, a major advantage.
- Backlinks from references to citations.

Footnote Approach: Disadvantages

- Inability to combine footnotes and in-text citation references on the same page.

Description List (`dl`) Approach: Disadvantages

- Manual numbering, introducing potential for errors and increased maintenance.
- Absence of backlinks from references to citations, requiring complex - workarounds (e.g., link render hooks) with potential for conflicts.
- Lack of indentation options for bottom-of-page references.
- Requirement for site configuration adjustments (albeit minor), adding an extra step for module users.
